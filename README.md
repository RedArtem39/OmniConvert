# OmniConvert 🎬📸

**OmniConvert** — современный, открытый и абсолютно бесплатный медиа-конвертер и компрессор для Android на **Kotlin + Jetpack Compose**. Создан как чистая альтернатива перегруженным рекламой и подписками приложениям (вроде Video Converter by Inverse.AI).

---

## ✨ Возможности

### 🎬 Видео
- **Форматы**: MP4, MKV, MOV, WebM, GIF.
- **Аппаратное ускорение**: кодирование через чипы Qualcomm Snapdragon / MediaTek (`h264_mediacodec`, `hevc_mediacodec`) — в 5–10 раз быстрее и без нагрева.
- **Умное сжатие под мессенджеры**: пресеты для Discord (25 МБ), Telegram (10 МБ, 50 МБ) или ручная настройка качества через CRF (18–32).
- **Обрезка видео**: точный выбор начала и конца ролика через таймкоды.
- **Масштабирование**: 1080p, 720p, 480p, 360p, оригинал.

### 📸 Фото (то, чего нет в большинстве конвертеров)
- **Пакетная обработка**: выбор и конвертация нескольких фото одновременно.
- **Форматы**: WEBP, JPG, PNG, HEIC, AVIF.
- **Сжатие и ресайз**: плавный слайдер качества (10–100%) и масштабирование (100%, 75%, 50%, 25%).
- **Приватность**: автоматическая очистка EXIF-метаданных (геолокация, дата, модель камеры).

### 🎵 Аудио
- Быстрое извлечение чистого звука из видео в **MP3, AAC, FLAC, Opus, WAV** с выбором битрейта (128–320 kbps).

### 🎨 Дизайн и эргономика
- **Правило 60-30-10**: спокойный матовый тёмный фон, мягкие контуры карточек, сдержанный сланцево-синий акцент.
- **Material You**: динамическая адаптация под цвета обоев (Android 12+).
- **Фоновая работа**: Foreground Service с уведомлением и прогресс-баром в шторке, поддержка WakeLock.
- **Сохранение в Галерею**: мгновенный экспорт в системные папки `Movies` и `Pictures` через Android MediaStore API.
- **0 рекламы, 0 трекеров, 0 подписок.**

---

## 🛠️ Стек технологий

- **Язык**: Kotlin 2.0
- **UI**: Jetpack Compose, Material 3 (Material You)
- **Медиа-движок**: FFmpeg-Kit + Android MediaCodec Hardware Encoders
- **Графика**: Android Bitmap API + ExifInterface
- **Загрузка изображений**: Coil Compose
- **Сборка**: Gradle 8.10, Android SDK 35

## 📦 Сборка из исходников

```bash
git clone https://github.com/RedArtem39/OmniConvert.git
cd OmniConvert
./gradlew assembleDebug
```

Готовый APK появится в:
`app/build/outputs/apk/debug/app-debug.apk`
