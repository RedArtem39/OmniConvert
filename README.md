# OmniConvert

OmniConvert — открытый и бесплатный медиа-конвертер и компрессор для Android на Kotlin и Jetpack Compose. Разработан как легковесная альтернатива коммерческим утилитам без рекламы, водяных знаков и подписок.

---

## Возможности

### Видео
- Форматы: MP4, MKV, MOV, WebM, GIF.
- Аппаратное ускорение: поддержка энкодеров MediaCodec (`h264_mediacodec`, `hevc_mediacodec`) для быстрого кодирования без перегрева.
- Сжатие под размер: расчет битрейта под лимиты Discord (25 МБ) и Telegram (10 МБ, 50 МБ) или ручная настройка качества через CRF (18–32).
- Обрезка: выбор интервала обрезки по таймкодам.
- Разрешение: оригинал, 1080p, 720p, 480p, 360p.

### Фото
- Пакетная обработка нескольких изображений одновременно.
- Форматы: WEBP, JPG, PNG, HEIC, AVIF.
- Сжатие и масштабирование: регулировка качества (10–100%) и ресайз (100%, 75%, 50%, 25%).
- Приватность: очистка EXIF-метаданных (геолокация, дата, модель камеры).

### Аудио
- Извлечение аудиодорожек из видеофайлов в MP3, AAC, FLAC, Opus, WAV с выбором битрейта (128–320 kbps).

### Интерфейс и архитектура
- Дизайн по правилу 60-30-10: нейтральный темный фон, сдержанные поверхности контейнеров и неяркие акценты.
- Material You: поддержка динамической палитры Android 12+.
- Фоновый процесс: Foreground Service с постоянным уведомлением и WakeLock для предотвращения засыпания CPU при длительном кодировании.
- Интеграция с хранилищем: сохранение готовых файлов напрямую в галерею через MediaStore API.
- Без рекламы, аналитики и встроенных покупок.

---

## Стек технологий

- Язык: Kotlin 2.0
- UI: Jetpack Compose, Material 3
- Обработка медиа: FFmpeg-Kit, Android MediaCodec
- Обработка изображений: Android Bitmap API, ExifInterface
- Загрузка изображений: Coil Compose
- Сборка: Gradle 8.10, Android SDK 35

## Сборка

```bash
git clone https://github.com/RedArtem39/OmniConvert.git
cd OmniConvert
./gradlew assembleDebug
```

`app/build/outputs/apk/debug/app-debug.apk`
